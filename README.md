# E-Commerce Shopping Cart

A simple command-line shopping cart application written in C.

## Features

- View product catalog
- Add items to cart
- Remove items from cart
- View cart contents
- Checkout with tax calculation

## How to Compile and Run

1. Ensure you have MinGW or GCC installed.
2. Compile: `gcc Demo.c -o shopping_cart.exe`
3. Run: `./shopping_cart.exe`

## Usage

Follow the on-screen menu to interact with the cart.
